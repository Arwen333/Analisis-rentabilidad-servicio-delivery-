# Análisis-rentabilidad-servicio-delivery

Este repositorio constituye el proyecto final integral de la asignatura **Modelos paramétricos y de Series de Tiempo**, representando un ejercicio académico exhaustivo dedicado al estudio, desarrollo y análisis avanzado de los factores que afectan la rentabilidad en servicios de delivery, mediante la aplicación de metodologías estadísticas y econométricas implementadas en el entorno de programación R.

El proyecto se enmarca dentro del campo del análisis de datos aplicado a negocios, abordando uno de los temas de mayor relevancia en la economía digital actual: la rentabilidad de los servicios de entrega a domicilio. A través de técnicas de modelación paramétrica y series de tiempo, este estudio busca identificar las variables clave que inciden en los márgenes de ganancia, optimizar la asignación de recursos y proporcionar insights valiosos para la toma de decisiones estratégicas.

---

## 📊 Objetivos del Proyecto

- Identificar y analizar las variables que afectan la rentabilidad en servicios de delivery
- Aplicar modelos paramétricos para cuantificar el impacto de cada factor
- Implementar análisis de series de tiempo para detectar patrones y tendencias
- Generar visualizaciones que faciliten la interpretación de los resultados
- Proporcionar recomendaciones basadas en evidencia empírica para la optimización del servicio

---

## 🛠️ Tecnologías Utilizadas

- **R** (lenguaje de programación)
- **RStudio** (entorno de desarrollo)
- **Paquetes de R**:

| Paquete | Función |
|---------|---------|
| `tidyverse` | Manipulación y visualización de datos |
| `dplyr` | Transformación y filtrado de datos |

| `lubridate` | Manejo de fechas y tiempos |
| `forecast` | Modelado y predicción de series de tiempo |
| `tseries` | Análisis de series temporales |

| `readr` | Importación de datos estructurados |
